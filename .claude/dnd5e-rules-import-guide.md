# D&D 5e 2014 中文规则导入指南

> 本文档是给**另一个 Claude Code 项目**的工作指南。目标：从中文 PDF 提取 D&D 5e 2014 规则，生成 markdown 文件，供 `trpg-battle` 项目使用。

---

## 1. 背景

`trpg-battle` 项目是一个 D&D 战斗 DM 系统，AI 作为 DM 裁定规则。规则文件存放在 `rules/` 目录下，被 AI 在战斗中查阅。

**当前问题**：
- `5e-phb.md` 和 `5e-spells.md` 是 **5.5e (2024) 英文 OCR 扫描**导入的，存在版本错误和 OCR 噪音
- `5e-mm.md` 虽然基于 2014 中文数据，但经核查存在**严重数据错误**（见下方§1.1）
- 版本不一致（怪物 2014 + 规则 2024）导致裁定冲突
- AI 的训练数据对 2014 版更熟悉，中文规则文件能减少翻译层出错

**目标**：用中文 PDF (2014 5e) 重新生成全部五个规则文件：`5e-phb.md`、`5e-spells.md`、`5e-mm.md`、`5e-dmg.md`（战斗裁定）、`5e-dmg-campaign.md`（战役创作）。

### 1.1 现有 `5e-mm.md` 已知错误

经与 PDF 原文交叉验证，现有怪物文件存在以下**已确认错误**，必须在重新导入时修正：

#### 翻译名/种族类型错误

| 怪物 | 当前错误 | PDF 正确翻译 |
|------|--------|-----------|
| Hobgoblin | 鳄鱼人/强鱼人，人形生物（鱼人）| **大地精**，类人生物（类地精）|
| Bugbear | 地精熊/虫熊人 | **熊地精** |
| Gnoll | 妖格诺 | **豺狼人** |
| Kobold | 柯布德 | **狗头人** |

#### 数值/规则错误

| 怪物 | 错误内容 | 正确内容（PDF 原文）|
|------|--------|----------------|
| **Shadow** | 伤害免疫写了"冷冻、闪电、雷鸣+非魔法BPS" | 这些应为**伤害抗性**（且应包含强酸、火焰）；实际伤害免疫为**腐蚀、毒素** |
| **Shadow** | 状态免疫缺少恐惧、麻痹 | 应为：力竭、**恐惧**、擒抱、**麻痹**、石化、中毒、倒地、束缚 |
| **Shadow** | 伤害弱点"辐射" | PDF 用词为**光耀** |
| **Banshee** | 哀嚎效果：失败受3d6伤害，成功降至0HP | **写反了**！失败=降至0HP，成功=受10(3d6)精神伤害 |
| **Yeti** | 状态免疫：冻僵（frightened）| PDF 中 Yeti **没有任何状态免疫**；且"冻僵"不是 frightened 的翻译 |
| **Yeti** | 冻眼 WIS DC 13 | 应为 **CON DC 13**（体质豁免）|
| **Hill Giant** | 投石附加 STR DC 17 击倒 | Hill Giant 投石**没有击倒效果**（这是 Stone Giant 的能力）|
| **Carrion Crawler** | 触须 +8 命中 | CR 2 怪物 +8 异常高，需按 PDF 核实 |

> **注意**：以上仅为抽查发现。实际错误可能更多，重新导入时应逐条对照 PDF 原文。

## 4. 格式规范

### 4.1 通用格式

- 使用 GitHub Flavored Markdown
- 中文为主，专有名词格式：`中文名（English Name）` 或 `English Name（中文名）`——与原文 PDF 保持一致即可
- 数值必须精确：AC、HP、伤害骰、DC、距离、持续时间等不可有误
- 每个文件开头需要：
  - `#` 标题行
  - `>` 引用块说明来源和版本
  - `## Index` 目录

### 4.2 PHB 文件结构参考

```markdown
# D&D 5e — 玩家手册规则参考

> 来源：D&D 5e 玩家手册 2014（中文译文版本 1.7，含 2018 errata 2.0）
> 配套文件：`5e-mm.md`（怪物）、`5e-spells.md`（法术）

## Index

1. [核心机制](#1-核心机制) — 能力值、检定、优势劣势、熟练加值...
2. [战斗](#2-战斗) — 战斗流程、动作、攻击、掩护...
...

---

## 1. 核心机制

### 1.1 能力值（Ability Scores）
（内容）

### 1.2 能力调整值（Ability Modifiers）
| 能力值 | 调整值 | 能力值 | 调整值 |
|:-----:|:------:|:-----:|:------:|
| 1     | -5     | ...   | ...    |
```

### 4.4 关键标记

法术列表中的标记：
- `(C)` = 专注（Concentration）
- `(R)` = 仪式（Ritual）
- `(M)` = 需要特殊材料成分（有 GP 价值的）

### 4.5 表格格式

数值表格（武器、护甲、CR/XP 等）使用 markdown 表格，对齐方式用 `:---:` 居中或 `---:` 右对齐（数字列右对齐）。

## 5. 导入流程

### 5.0 核心原则

- **一次只处理一本书**，不要跨书操作
- **每个对话只提取 1-2 个章节**，context 堆积后质量会下降
- **每个章节提取完成后立即校验**，不要等全部做完再查
- **context 变长后果断开新对话**，带上本指南 + 已完成的输出文件继续
- 输出文件采用**追加模式**：每个对话在已有文件末尾追加新章节内容

### 5.1 整体顺序

按手册分五轮，每轮内按章节逐步完成：

```
轮次 1：PHB（玩家手册）→ 输出 5e-phb.md          （11 个对话）
轮次 2：Spells（法术章节，仍从 PHB 提取）→ 输出 5e-spells.md （6 个对话）
轮次 3：MM（怪物图鉴）→ 输出 5e-mm.md            （7 个对话）
轮次 4：DMG 战斗 → 输出 5e-dmg.md               （11 个对话）
轮次 5：DMG 战役 → 输出 5e-dmg-campaign.md       （10 个对话）
                                       合计：45 个对话
```

### 5.2 轮次 1：PHB — 分对话计划

每个对话处理 1-2 章，产出追加到 `5e-phb.md`。

## 6. 质量验证

导入完成后，执行最终验证：

### 6.1 交叉验证

用以下方式验证数值正确性：

1. **职业 HP 骰**：每个职业的 Hit Die 是否正确？（如 Barbarian d12, Fighter d10, Wizard d6）
2. **法术参数**：随机抽 10 个法术，对比 PDF 原文的射程/伤害/持续时间
3. **武器表**：全部武器的伤害骰/属性是否完整
4. **护甲表**：AC 值和穿戴条件是否正确
5. **状态效果**：全部状态的描述是否完整

### 6.2 怪物数据验证

MM 数据必须逐条对照 PDF，重点检查以下易错项：

1. **中文名与 PDF 目录一致**：对照 MM PDF 第 3 页目录
2. **伤害抗性 vs 伤害免疫**：这两个概念必须严格区分，不可混淆
3. **状态免疫**：逐条核对，不可遗漏或添加 PDF 中没有的条目
4. **豁免类型**：STR/DEX/CON/INT/WIS/CHA 必须与 PDF 一致（如 Yeti 冻眼是 CON 不是 WIS）
5. **攻击加值**：验证是否与能力值+熟练加值匹配（异常值需与 PDF 原文核实）
6. **成功/失败效果**：特殊能力的豁免成功和失败效果不可写反
7. **种族类型**：人形生物（类地精）、不死生物、怪兽等，必须与 PDF 一致

### 6.3 五文件交叉一致性

确保五个文件之间不矛盾：
- CR/XP 对照表（MM）与遭遇难度表（MM/DMG-campaign）一致
- 状态效果定义（PHB 附录 A）与 MM 状态速查一致
- 攻击/豁免规则（PHB 战斗章）与 MM 数据块中的用法一致
- 法术效果（spells）与 MM 中施法型怪物引用的法术一致
- 魔法物品效果（DMG）与 PHB 装备规则一致（如 +1 武器的攻击加值计算）
- 怪物 CR 基准表（DMG 战斗）与创作怪物流程（DMG 战役）一致
- 毒药/疾病效果（DMG 战斗）与 MM 中相关怪物能力描述一致
- 陷阱 DC/伤害（DMG 战斗）与伤害危害度表自洽

## 7. 注意事项

1. **不要混版本**：全部内容来自 2014 PDF，不要从记忆中补充 2024 内容
2. **不要省略**：职业特性要完整（每级特性都要列出），法术描述不能缩写
3. **保留原文术语**：PDF 中的中英对照术语保持原样
4. **页码标注**：如果方便，在每个大章节开头标注 PDF 页码范围，便于后续校对
5. **怪物数据必须重做**：现有 `5e-mm.md` 有严重错误（见 §1.1），需从 PDF 完全重新导入
6. **`combat-tactics.md` 不用动**：这是自定义文件，与版本无关
7. **怪物翻译名以 PDF 目录为准**：大地精（不是鳄鱼人）、熊地精（不是地精熊）、豺狼人（不是妖格诺）、狗头人（不是柯布德）
8. **DMG 拆分为两个文件**：`5e-dmg.md`（战斗裁定用）和 `5e-dmg-campaign.md`（战役创作用），避免 AI DM 战斗时加载不相关的冒险设计理论
9. **DMG 魔法物品必须完整**：魔法物品是 DMG 最大的内容块（约 50 页），分 4 个对话逐字导入，不可省略
10. **DMG 战斗文件优先于战役文件**：轮次 4（战斗）优先完成，轮次 5（战役）可延后
