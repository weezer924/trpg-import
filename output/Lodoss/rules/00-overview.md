## System Overview

This game is a tabletop RPG based on the system of the computer version of Record of Lodoss War. A playful GM and enthusiastic players create a story through conversation.

Although it is based on the computer version of Record of Lodoss War, human processing ability has its limits, so we have simplified complex calculations as much as possible. Furthermore, several improvements have been made to create a simple system suitable for beginners. **Character levels handled by this system are levels 1 through 7.**

> **关于本系统**：罗德岛战记 Companion I（1989）是 Group SNE 在 Lodoss 题材成名后基于 PC 版游戏系统开发的桌面 TRPG，是 Sword World RPG 的设计前身。处理 1-7 级角色。

## Dice Explanation 骰子说明

This game uses several types of dice. A 6-sided die is represented as **D6** (D stands for dice). Similarly:

- **D6** — 6-sided die
- **D8** — 8-sided die
- **D10** — 10-sided die

**D100** does not represent a 100-sided die. **D100** here means using two D10s to generate a random number from 1 to 100. One die represents the tens place and the other represents the ones place.

- Example: First die shows **3**, second shows **5** → result is **35**
- If both show **0** → it indicates **100**

**D2** is not a 2-sided die. It means determining 1 or 2: roll a die — if odd, it's 1; if even, it's 2.

> **骰类速查**：D6 / D8 / D10 是常规多面骰；D100 = 2D10（一颗作十位、一颗作个位，00 = 100）；D2 = 1D6 取奇偶。
