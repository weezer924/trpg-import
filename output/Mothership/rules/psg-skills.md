## 概述

技能代表了角色在特定领域积累掌握的知识、手艺、技术和训练。每当你进行属性检定或是豁免时，倘若具备相关技能，就能将技能奖励附加到属性或是豁免当中（让你投骰要低于的数值更高）。

每个职类起始都具备一些技能，角色可以经由长期学习和严格的技能训练来获得更多技能。

| 等级 | 加成 |
|---|---:|
| 没有技能 No Skill | +0 |
| 受训技能 Trained  | +10 |
| 专家技能 Expert   | +15 |
| 大师技能 Master   | +20 |

## 没有技能（+0）NO SKILL

没有技能并不意味着对这个范畴一无所知，而且通常也并非意味着你无法尝试，只是代表你在高压情况下没有足以果断行动的经验或专门技术。因此，你通常不会有奖励，而且根据任务的复杂程度，可能投骰还会带有劣势 [−]（或是根本无法尝试）。

> 优势 & 劣势的更多内容见第 19.1 页（→ `psg-checks-and-stress.md#优势劣势`）。

> **范例：逃离陨石**
>
> **监守**：那么大家穿着真空服在船底行走，有磁力靴吗？
>
> **菲尔**：老哥，有的。
>
> **监守**：行，你们能听到通信器里面传来了白噪音，然后瞥见了一个信号弹。
>
> **菲尔**：呃，我们遇到状况了。你们有看到什么吗？
>
> **克莉奥**：咱们有看到什么吗？
>
> **监守**：你们的扫描仪开始闪烁，然后向你们传达了会在十秒后与陨石雨发生撞击的警告。
>
> **菲尔**：该死，我要跑路了。
>
> **监守**：你穿着磁力靴，速度快不起来，而且还有碍事的真空服。你要进行一次带有劣势的速度检定。
>
> **菲尔**：我有零重力，这能派上用场吗？
>
> **监守**：当然可以，数值可以加十。
>
> **菲尔**：我的速度是 36，加上十就是 46，然后我投出了……54 和 77，妈的，关键失败。

## 受训技能（+10）TRAINED SKILLS

你在这个领域接受了相当于学士学位的标准培训，或是接受过几年的在职培训。

| 技能 | 描述 |
|---|---|
| 考古学 Archaeology | 古代文化和人工制品。 |
| 艺术 Art | 某一物种的创造力和想象力的表达或应用。 |
| 运动 Athletics | 身体素质、运动和竞赛。 |
| 植物学 Botany | 对植物生命的研究。 |
| 化学 Chemistry | 对物质及其化学元素和化合物的研究。 |
| 计算机 Computers | 熟练使用计算机及其网络。 |
| 地质学 Geology | 对任何陆地行星或其卫星的固体特征的研究。 |
| 工业装备 Industrial Equipment | 安全和正确使用重型机械和工具（外骨骼、叉车、钻头、破碎机、激光切割机等）。 |
| 临时拼凑 Jury-Rigging | 只使用手边的工具和材料临时修理。 |
| 语言学 Linguistics | 对语言的研究（包括现存、消亡和未经发现）。 |
| 数学 Mathematics | 对数字、数量和空间的研究。 |
| 军事训练 Military Training | 提供给所有军事人员的基本训练。 |
| 外环门道 Rimwise | 关于外环殖民地、习俗和银河系中险恶地带的实用知识和诀窍。 |
| 神学 Theology | 对某一宗教的神祇或祭拜的研究。 |
| 零重力 Zero-G | 真空中干活的实用诀窍、分辨方向、操作太空服等。 |
| 动物学 Zoology | 对动物生命的研究。 |

> 译注：专家和大师技能的前置均另外在人物卡中以箭头标出，未写在正文当中。为了便于浏览这里摘录补全，**满足一项即可**。版本：v0.10。

## 专家技能（+15）EXPERT SKILLS

你已经获得了等同于博士的学位，或是在这个领域具备多年经验。专家技能一般应该是受训技能的某个子集或特定侧重。

| 技能 | 描述 | 前置（任一） |
|---|---|---|
| 小行星采矿 Asteroid Mining | 用于开采小行星的工具和流程训练。 | 地质学、工业装备 |
| 生态学 Ecology | 对有机物及其与所在环境关系的研究。 | 植物学、地质学 |
| 爆炸物 Explosives | 设计和有效使用爆炸装置（炸弹、手雷、炮弹、地雷等）。 | 临时拼凑、化学、军事训练 |
| 战地医疗 Field Medicine | 紧急医疗护理和治疗。 | 动物学 |
| 枪械 Firearms | 安全有效地使用枪械。 | 军事训练、外环门道 |
| 骇入 Hacking | 不经授权登入计算机系统和网络。 → 网络 / 节点 / 安保 / 反应规则见 `supplements/hack-manual.md`。 | 计算机 |
| 近身搏斗 Hand-To-Hand Combat | 近战格斗、斗殴、武术等等。 | 军事训练、外环门道、运动 |
| 机械修理 Mechanical Repair | 修理损坏的机器。 | 工业装备、临时拼凑 |
| 神秘主义 Mysticism | 心灵上对于隐秘知识的领悟。 | 艺术、考古学、神学 |
| 病理学 Pathology | 对疾病原因和影响的研究。 | 动物学、植物学 |
| 药理学 Pharmacology | 对药物和施药的研究。 | 化学 |
| 物理学 Physics | 对物质、运动、能量及其时空上影响的研究。 | 数学 |
| 驾机 Piloting | 飞行器、航天器和其他载具的操作和控制。 | 零重力 |
| 心理学 Psychology | 对行为和人类心智的研究。 | 语言学、动物学 |
| 荒野生存 Wilderness Survival | 适用于自然环境中基本生活必需品（食物、水、住所）的诀窍。 | 植物学、军事训练 |

## 大师技能（+20）MASTER SKILLS

你是所在领域的佼佼者，深谙最为新锐的技术，或是冷门且极其专业的信息。由于侧重如斯，大师技能在广度上比起受训技能更为狭窄。

| 技能 | 描述 | 前置（任一） |
|---|---|---|
| 人工智能 Artificial Intelligence | 对机械展现出的智能的研究。 | 骇入 |
| 指挥 Command | 领导力、管理和权威性。 | 驾机、枪械 |
| 神经机械学 Cybernetics | 有机体与机械之间在物理和神经上的相互作用。 | 机械修理 |
| 工程学 Engineering | 引擎、机械和建筑设计、构筑和使用。 | 机械修理 |
| 外星生物学 Exobiology | 对智能外星生命的研究和搜索。 | 病理学 |
| 超空间 Hyperspace | 超光速旅行。 | 驾机、物理学、神秘主义 |
| 行星学 Planetology | 对行星和其他天体的研究。 | 生态学、小行星采矿 |
| 机器人学 Robotics | 对机器人、无人机和仿生人的设计、维护与操作。 | 机械修理 |
| 知性学 Sophontology | 研究非人类实体的行为和心智。 | 心理学 |
| 手术 Surgery | 对活体或死亡生物进行手术。 | 病理学、战地医疗 |
| 异种秘教 Xenoesotericism | 关于非人类实体的隐晦信仰、神秘主义和宗教。 | 神秘主义 |

## 技能训练 SKILL TRAINING

### 训练一项技能 TRAIN A SKILL

学习一项新技能需要耗费对应的时间和信用点。

| 等级 | 时长 | 材料费 |
|---|---:|---:|
| 受训技能 | 2 年 | 10kcr |
| 专家技能 | 4 年 | 50kcr |
| 大师技能 | 6 年 | 200kcr |

- 训练**专家技能**需要一项**受训技能前置**。
- 训练**大师技能**需要一项**专家技能前置**。

### 为什么需要这么长时间？

技能训练期间，假定角色还有全职工作，参与任务并且正常过活。若是全日制学习（譬如上学），那么训练时长**减半**。监守可能会允许用额外资源（私人辅导、AI 辅助、神经机械模块、智能软件等）来减少所需时间。

## 军事训练 MILITARY TRAINING

军事训练是常规技能训练的**特殊例外**，原因有二：

1. **不需要费用**。
2. 角色必须和当地的殖民地陆战队军团签署一份为期 **6 年**的合同。

至于在服役期间发生了什么，进行一次**战斗检定**：

| 战斗检定结果 | 收获 |
|---|---|
| **成功** | 获得军事训练、运动和**两项受训技能**；战斗 +10，另一属性 −10；获得陆战队员的创伤反应。 |
| **关键成功** | 如同成功，但你可以**不选两项受训技能，而是选一项专家技能**。 |
| **失败** | 获得军事训练、运动和**一项受训技能**，以及陆战队员的创伤反应。 |
| **关键失败** | 你在行动期间**丧生**。 |

> **范例：技能训练**
>
> **监守**：好了，完成一些文件整理和强制性的安全培训后。公司就让你们重新开始工作，将货物从银河系一端送到另一端。
>
> **诺克斯**：啊，谢天谢地，我从来没想过自己能因为重回岗位而心怀感激……
>
> **监守**：确实如此，你们在休息期间还有什么要做的吗？
>
> **克莉奥**：我在进行机器人学技能训练，还剩下……呃……四十二个月。
>
> **诺克斯**：我觉得自己的角色实际上想要摆脱公司生活，并且更积极地参与到行动当中。有办法让他接受军事训练之类的吗？
>
> **监守**：当然可以，但这份合同为期六年，所以你本质上要去投一个新角色，然后将原来这个放到一边，直到他期满后重出江湖为止。另外，他可能会在中途死亡，你觉得怎么样？
>
> **诺克斯**：嗯，行啊，实际上听着很不错。
>
> **监守**：顺便，大家都可以这样。临时停用某个角色，然后创建其他人物。提前告知一下让我有时间就新角色进行准备就可以了。
>
> **克莉奥**：啊——听起来很有趣。
>
> **监守**：当然啦。好了，诺克斯，你的角色在附近的站点招到了一位人员入伙。对于其他人而言，六个月过去了，各位可以在角色卡上标一下。
