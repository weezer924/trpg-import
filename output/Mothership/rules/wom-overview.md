## 系统简介

**《母舰》监守操作手册 Mothership Wardens Operations Manual** 是 Mothership RPG 的监守（Warden）端核心书。本书在 PSG 玩家手册的规则之上，提供：

- **首回游戏场次准备**（准备 10 步：组织 → 邀请 → 阅读 → 选剧本 → 找恐怖 → 求生 → 解决 → 拯救 → 画地图 → 完善）
- **TOMBS 循环**（**T**ransgression 越界、**O**men 预兆、**M**anifestation 显现、**B**anishment 放逐、**S**lumber 沉睡）
- **求生 / 解决 / 拯救**三轴剧本设计法
- **主持流程**（教学、6 步流程、社交 / 暴力裁定、房规）
- **战役构建**（风格 / 框架 / 派系 / 公司 / 经济 / 收尾）

参见专题文件：`wom-prep.md`、`wom-scenario-design.md`、`wom-running-game.md`、`wom-investigations-and-ships.md`、`wom-campaign-design.md`、`wom-worldbuilding-tables.md`。

## 内容警告 CONTENT WARNING

《母舰®》是面向**成年受众**的恐怖游戏。包含**暴力、粗俗语言、部分性元素、药物滥用**，以及对**精神疾病、创伤、压力与恐慌**的描绘，可能并不适合所有观众。敬请知悉。

> 团体安全工具与桌边礼仪见 → `psg-overview.md#安全指引-safety-instructions` 与 `wom-running-game.md`（待导入）。
