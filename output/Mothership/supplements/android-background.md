## 使用说明 OVERVIEW

使用以下表格来自定义你的仿生人。你可以通过投骰创造出制造你仿生人角色的自定义公司（以及仿生人的用途），且使用自定义惊恐表来给你的仿生人一些与陆战队员不同的惊恐时刻。

> **关联规则**：通用压力 / 惊恐机制见 → [psg-checks-and-stress.md](../rules/psg-checks-and-stress.md)。仿生人职业起始调整见 → [psg-character-creation.md](../rules/psg-character-creation.md)。

## 谁制造了我的仿生人？WHO MADE MY ANDROID?

骰 1d10 并组合对应行（或骰 4d10 混合结果）来决定制造你的仿生人角色（甚至所有仿生人）的公司。

> 由于名称生成器的性质以及译者水平有限，推荐使用本表格生成名字之后自行翻译（保留英文亦可）。

| D10 | 前缀 | 其它前缀 | 后缀 | 其它后缀 | 形容词 | 企业类型 |
|---:|---|---|---|---|---|---|
| 01 | VIVO- | MECHA- | -SOPHIA | -ACEOUS | PROMETHEAN | ENTERPRISE |
| 02 | BIO- | ADIP- | -DERM | -FLECT | GENERATIVE | CONVERGENCE |
| 03 | ANTHROPO- | TACHY- | -IASIS | -ZOA | INNOVATIVE | MINDSHARE |
| 04 | ASTER- | GNATH- | -CYTE | -STOME | AGONAL | INSTITUTE |
| 05 | TOXICO- | SOMATA- | -VERGE | -IAE | STREAMLINED | DevOp |
| 06 | HYPER- | PHILO- | -URA | -SPIRE | HOLISTIC | CONSORTIUM |
| 07 | NEMAT- | THERMA- | -PHYLL | -DUCT | ARTISAN | MANUFACTORY |
| 08 | ZO- | MALAC- | -STASIS | -EMIA | ENGAGED | INCUBATOR |
| 09 | ZYM- | XYL- | -METRY | -PHONE | SKEUOMORPHIC | NURSERY |
| 10 | ODONT- | PNEUMO- | -ATE | -LYST | ADVANCED | CATALYST |

**生成方式**

- **快速法（1d10）**：投一次 d10，把同一行的"前缀 + 后缀 + 形容词 + 企业类型"拼起来。
  - 范例：(1d10: 7) → THERMA- + -PHYLL + ARTISAN + MANUFACTORY = **THERMAPHYLL ARTISAN MANUFACTORY**
- **混合法（4d10）**：投 4 次 d10，依次取"前缀 / 后缀 / 形容词 / 企业类型"列。
  - 范例：(4d10: 2-6-10-3) → BIO- + -SPIRE + ADVANCED + MINDSHARE = **BIOSPIRE ADVANCED MINDSHARE**
- 想要更复杂的名字，可改用"其它前缀 / 其它后缀"列叠加（如 MECHA-VIVO-SOPHIA-DERM）。

## 仿生人起源 ANDROID ORIGIN

骰 1d10 决定该仿生人来自何种生产/合成路径。起源决定了一些可见特性，可作为角色 Trauma Response / Want / 履历的钩子。

| D10 | 起源 | 特性 |
|---:|---|---|
| 01 | 回收囚犯 | 安装有固件，只有部分记忆，可能受到悬赏 |
| 02 | 培养缸 | 蹼状手指，不自然的眼睛 |
| 03 | 披着合成人类外壳的机器人 | 沉重，冰冷，对感官体验感到困惑 |
| 04 | 被匆忙改装的克隆人 | 外貌与普通仿生人类似，有已知身体缺陷，希望与本体见面 |
| 05 | 驻外武官随员 | 冷酷无情，战术思维，斯巴达式作风，逻辑严密 |
| 06 | 类人仿生体 | 身体缓慢衰老，外貌位于恐怖谷中 |
| 07 | 未知外星科技 | *（PDF 留空，由玩家与监守共同设计）* |
| 08 | *（PDF 留空，由玩家与监守共同设计）* | *（PDF 留空，由玩家与监守共同设计）* |
| 09 | 生化怪人 | 可怖伤疤，拼接身体，碎片记忆 |
| 10 | 谍报复制人 | 外貌与某个 VIP 或特定团体相仿，并因此被对方记恨 / 被对方的仇家记恨；经常产生记笔记的冲动；习惯于分析威胁 / 弱点 |

> **注**：原 PDF 中 07 行只列了"未知外星科技"且未给特性，08 行整行留空 — 这是原作有意保留给桌面自填的空位（home-brew slots），导入时如实保留。

## 仿生人惊恐表 ANDROID PANIC TABLE

> **何时使用**：仿生人角色触发惊恐检定（Panic Check）时，可由监守裁定改用本表替换通用惊恐表（见 → [psg-checks-and-stress.md#惊恐检定-panic-check](../rules/psg-checks-and-stress.md)）。掷 **2d10**（范围 02–30；通用表为 2d10+压力）。

| 2D10 | 仿生人惊恐反应 |
|---:|---|
| 02–03 | **报出事情发生的概率**：1 小时内团队的所有掷骰带有优势 [优]。 |
| 04–05 | **解释单词词源**：1 小时内知识类检定带有优势 [优]。 |
| 06–07 | **将物品摆放成几何形状**：身边所有人获得 1 压力。 |
| 08–09 | **给灰尘按粒分级**：无法进行其它行动，身边所有人获得 2 压力。 |
| 10–11 | **间断地发出像故障传真机一样的尖啸**：尖啸声和间断组成摩尔斯电码，无法交流或潜行。身边所有人获得 2 压力。 |
| 12–13 | **报出错误概率**：（坚称不可能的行动非常简单，非常简单的行动不可能达成）……持续 2d10 小时，非常烦人。任何尝试某种复杂工作的人需要通过一次恐惧豁免，否则获得 1d10 压力。 |
| 14–15 | **重复生硬的小动作**：你进行手动工作时带有劣势 [劣]，身边所有人获得 2 压力。 |
| 16–17 | **失去情商**：不断指出队伍中其他人的恐惧症缺乏理性，并积极尝试触发它们。 |
| 18–19 | **不断重复当前动作**：由于一直重复同一动作受到 1d10 伤害。身边所有人通过恐惧豁免，否则获得 1d10/2 压力。 |
| 20–21 | **对于危险的来源产生虚无的崇拜之情**：身边所有人与其对抗时投骰获得劣势 [劣]。当对抗失败时，所有人通过一次恐惧豁免否则获得一种恐惧症。 |
| 22 | **杀心大起**：陷入狂暴，无论情况如何都不会从战斗中撤退，也不会遵循战术。 |
| 23 | **图灵测试失败**：难以表现出人性。每当你出现时团队成员都需要通过一次恐惧豁免，否则获得 1 压力。 |
| 24 | **系统过载**：倒地不起，陷入僵直状态，长达 1d10 小时重启失败。 |
| 25 | **逻辑核心烧毁**：非理性的狂暴行为，身边所有人进行一次惊恐检定。 |
| 26 | **威胁分析功能受损**：一找到机会就背叛团队，并相信自己在帮助乘组。在接下来的 1d10 小时内每次获得压力时额外获得 1d10 压力。 |
| 27 | **复合数据损坏**：骰两次（在本表上）。 |
| 28 | **固件故障**：在此表上骰 1d10，对应结果永久持续。 |
| 29 | **数据损坏**：监守永久接管该角色，噩梦般的故障。 |
| 30 | **融毁**：吉格尔式的头部爆炸，身边所有人获得一种恐惧症和 1d10/2 压力（恐惧豁免可避）。 |

**适用提示**

- 28 "固件故障"的 1d10 落在 02–11 段需把 d10 视作 d8 + 02（或由监守按照 2d10 的范围裁定具体子结果）。
- 25 "逻辑核心烧毁"触发的连锁惊恐检定使用通用惊恐表（见 PSG），或继续在本表上重投，由桌面约定。
