## 概述 OVERVIEW

对于母舰®玩家来说，**骇入** 是一种虽然危险但相当有利可图的技能。玩家们利用骇入可以打开门锁、劫持炮塔或窃取敏感信息。

大部分 **黑客检定** 都非常简单：气闸被电子锁锁住，黑客过一个智力（黑客）检定，如果成功，那么锁就开了。简单的不能再简单。

不过，如果你的场景需要一个更困难的挑战 — 比如黑入某个企业研究站的主数据库 — 那你可能会需要设计一个**网络**。

> **关联规则**：技能"骇入"的受训/专家/大师层级见 → [psg-skills.md](../rules/psg-skills.md)。智力检定与优劣势见 → [psg-checks-and-stress.md](../rules/psg-checks-and-stress.md)。

## 网络 NETWORKS

**网络** 是一种由相互连接的节点所组成的系统。一个网络可以是由数十个节点连接而成的庞大系统，也有可能是只包含几个节点的简单系统。

监守在场景准备时为每个目标网络列出：

- 它由哪些 **节点** 组成
- 节点之间如何相连（路由器 / 上行链接 / 桥接）
- 整个网络的 **反应等级**（默认随节点累加，亦可由监守整体设定）

---

## 节点 NODES

一个节点可以代表一个调制解调器、集线器、打印机、计算机、个人数字助理、电控设备，或者任何其它接入网络的软件或设备。

每个节点都包含以下三项属性：**功能 FUNCTION**、**安保等级 SECURITY**、**反应等级 RESPONSE**。

### 功能 FUNCTION

一个节点的"功能"是对它能做什么的简单描述。以下是几个例子：

- **接入点 Access Point**：用于访问网络。
- **数据库 Database**：用于存储重要信息（如任务报酬数据、设施地图、仓储清单、用户列表、监控录像等）。
- **路由器 Router**：其它节点可以通过连接至此节点互相通讯。黑客可以通过控制此节点改变网络通路，以便绕过网络中安保等级较高的节点。
- **防火墙 Firewall**：一个安保等级 / 反应等级较高的节点，用于防御黑客。
- **基础设施 / 硬件控制 Infrastructure**：用于控制此节点连接地点的基础设施（例如气闸、通风管道、门、照明、摄像头、引擎、反应堆、生命维持系统、武器等）。
- **上行链接 / 中继 / 桥接 Uplink / Relay / Bridge**：将一个网络与另一个网络相连。
- **终端 Terminal**：用于访问网络或本地内容的实体交互界面（例如个人电脑）。

### 安保等级 SECURITY

一个节点的 **安保等级** 反映了攻克该节点的难度，分为以下四种：

| 等级 | 说明 | 攻克方式 |
|---|---|---|
| **开放 Open** | 没有密码保护，也没有任何形式的安保措施 | 任何人都可以访问，无需检定 |
| **安全 Secure** | 标准安保 | 需进行一次骇入检定 |
| **坚固 Hardened** | 安保完备 | 需进行一次骇入检定 [劣] |
| **加密 Encrypted** | 极度安保 | **无法**通过骇入检定攻克。要访问必须使用拥有访问该网络权限的用户的 **个人密钥（PEK）**。个人密钥可通过偷窃、逼供、社会工程学，或黑入安保等级较低的节点（例如目标存储着个人密钥的个人电脑）获得 |

### 反应等级 RESPONSE

网络的 **反应等级** 用于衡量来自任何网络管理员、操作员、自动化安全程序、监管 AI 等安保系统的反应烈度。

- 范围：**无（不需要投骰）** ↔ **+5（快速而强烈的反应）**
- 每当黑客的骇入检定 **失败** 时，在 [反应表](#反应表-response-table) 中投 d10，**加上**该网络的反应等级。

## 反应表 RESPONSE TABLE

| D10 | 反应 |
|---:|---|
| 00 | 警告消息。网络反应 +1。 |
| 01 | 设备被远程关闭。 |
| 02 | 用户账号被锁定 1d10 小时。 |
| 03 | 安保人员前来调查。在 1d10 轮内到达。 |
| 04 | 网络伪造一个"目录"供黑客浏览，同时安保人员前来调查。 |
| 05 | 本网络和所有与本网络相连的网络锁定 1d10 小时。 |
| 06 | 本网络和所有与本网络相连的网络安保等级提升 1。 |
| 07 | 所有相连网络反应 +1。 |
| 08 | 设施停电。所有非必要电器关机。 |
| 09+ | 部署重装战术小队猎杀黑客。1d5 轮内到达。 |

**其他反应**（监守可裁定替换上表结果）：

- **拒绝服务 DoS**：网安系统尝试通过向黑客的硬件发送大量垃圾信息屏蔽黑客，导致黑入速度下降。
- **反向黑入 Reverse Hack**：网安系统尝试控制 / 摧毁用于赛博攻击的终端 / 碟板等。
- **病毒攻击 Virus**：网安系统使用病毒暂时瘫痪黑客的硬件。
- **电力过载 Surge**：网安系统向黑客的硬件中输入超高压电。
- **追踪身份 ID Trace**：网安系统尝试获取黑客的身份信息。
- **网络追踪 Net Trace**：网安系统尝试追踪黑客的物理位置。

## 用户账号 USER ACCOUNTS

玩家也可以不使用直接黑入网络的方式，而是通过盗窃、威吓或其它方式获取用户的身份认证（如密码、ID、身份徽章、PEK 等）来盗用其它用户的账号。虽然直接登录账号绕过了骇入检定，不过每个账号的权限都有所限制：

- **游客账户 Guest**：只有非常有限的权限，通常只能访问内网（如果有的话）、公司名录或线上帮助。
- **员工账户 Employee**：拥有对所有员工工作内容的访问权。
  - *例如*：船上的工程师可能会有工程网络的访问权，因此能够从自己的终端处控制飞船的推进器。员工通常能够访问电子邮件、地图、项目细节等公司敏感信息和文件。
- **管理员账户 Admin**：监管数名员工，因此拥有麾下所有员工的访问权。管理员可能是经理、团队领导、IT 人员或飞船军官。
- **超级用户 Superuser**：拥有对网络中所有内容的访问权，且常常同时活跃在数个互相连接的网络系统中。
  - *例如*：一个飞船上的超级用户应该能访问飞船上的所有网络 — 基础设施、武器系统、导航系统、雇员数据等……

超级用户账号是黑客的梦中情号，因此大部分时候都被严加看管或重重加密。不过，如果你的黑客能获得一个系统的根权限，那么就让他们随心所欲吧 — 这是他们应得的。

**用户账号能创造不少有趣的情境**，例如：

- 一个员工徽章可能能够打开太空站前几层的所有大门，然后用于登录连接着太空站安保网络的终端。
- 某些网络或设备可能一个相关的账号都没有 — 它们只能被手动黑入。
- 当然，获得某个特定用户账号的访问权可以让你获得黑入某些难以接触的网络的机会。

请把用户账号看作玩家黑入网络时除了黑客技能之外和玩家互动的另一种方式。

## 范例：跃迁 1 级科考船诺亚四号

这艘船拥有两个分别与船长的加密终端连接的网络（各由 6 个节点组成）。

### 乘组网络 CREW NETWORK

| 节点 | 功能 | 安保 | 反应 | 备注 |
|---|---|---|---:|---|
| 内网 | 数据库 | 开放 | 无 | — |
| 内网中枢 | 路由器 | 安全 | +1 | — |
| 游客终端 | 终端 | 开放 | 无 | — |
| 员工 1 终端 | 终端 | 损坏 | 无 | 已损坏，可作为入侵跳板 |
| 船长终端 | 终端 | **加密** | +3 | **超级用户**：可登录指挥网络 |
| 船长个人便携终端 | 便携终端 | 安全 | +1 | 储存 **船长的个人密钥（PEK）** |

### 指挥网络 COMMAND NETWORK

> 通过船长终端的加密链接连入。

| 节点 | 功能 | 安保 | 反应 | 备注 |
|---|---|---|---:|---|
| 设施中枢 | 路由器 | 坚固 | +2 | — |
| 生命维持控制 | 基础设施 | 坚固 | +5 | 反应最高，黑入风险最大 |
| 引擎控制 | 基础设施 | 坚固 | +4 | — |
| 跃迁导航 | 基础设施 | 坚固 | +2 | — |
| 通讯终端 | 终端 | 安全 | +1 | — |
| 企业链接 | 上行链接 | **加密** | 无 | 通往公司外网 — 黑客圣杯 |

**布局思路**：乘组网络是相对宽松的"前厅"，玩家容易借员工 / 游客身份溜进去；真正的目标（生命维持、引擎、跃迁导航、企业外联）都在指挥网络内，而进入指挥网络要么需要破解船长的加密终端，要么需要偷到船长的 PEK，要么需要从损坏的员工终端等弱点节点曲线穿越。
