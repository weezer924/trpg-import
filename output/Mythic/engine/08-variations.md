# Variations

> Optional rules and meta-strategies. Pick what fits your session; ignore the rest. Full detail in `→ rules/05-variations.md`.

## When To Use

- Before a session: pick which variations are active (chaos flavor, peril points, recording style).
- Mid-session: invoke Keyed Scenes / Thread Progress Track / Peril Points when the moment fits.
- For prepared adventures: switch to the prepared-adventure ruleset (Adventure Features, no Altered/Interrupt).

## Procedure

Each variation below is a self-contained module. Activate it explicitly.

### Getting Prepared For A Solo Adventure

Choose recording style up front:
- **Journal** (notebook), **Blog** (public), **Theater of the Mind** (memory), **Novelization** (write as you play), **Note & Edit** (notes during, prose after).
Sandbox vs Linear: sandbox works exceptionally well solo — start with PC + setting + a vague situation; let Mythic generate momentum.
> Detail: `→ rules/05-variations.md` §Getting Prepared.

### Determining NPC Statistics

For an unknown stat (HP, damage, AC, …): decide your expected value, then ask "Does the NPC have this stat?" with appropriate Odds. Apply the **NPC Statistics Table** (`→ tables/npc-statistics.md`):
- Yes → expected. Exc Yes → +25%. No → −25%. Exc No → −50%. Random Event → a special condition attached to this stat (Current Context Focus).
> Detail: `→ rules/05-variations.md` §Determining NPC Statistics.

### Getting The Most Out Of Sourcebooks

A sourcebook is **inspirational** (sparks ideas) or **practical** (used as written). Mix sources freely — spells from one game, monsters from another, traps from a third. Treat books as random tables: random page → random content. Sourcebooks themselves can be entries on the Characters List, called up by Random Events.
> Detail: `→ rules/05-variations.md` §Getting The Most Out Of Sourcebooks.

### Thread Progress Track

Force a chosen Thread to a definite end. Pick a Focus Thread; track Progress Points (10 / 15 / 20 — pick one). Earn Points via:
- **Progress** (significant in-Scene step) → +2 Points.
- **Flashpoint** (dramatic, important moment) → +2 Points; checks the box for the current 5-point phase. If a phase ends without a Flashpoint, one fires automatically as a Random Event with Current Context Focus.
- **Discovery Check** when stuck: PC takes a triggering action; ask "Is something discovered?" with Odds (never worse than 50/50). Yes → roll **1d10 + current Progress** on the **Thread Discovery Check Table** (`→ tables/thread-progress-track.md`). Exc Yes → roll twice and combine. Exc No → no further Discovery Checks this Scene.
- **Plot Armor** — until full Progress is reached, the Thread cannot resolve. A "Close A Thread" Random Event still plays out, but the Thread doesn't actually close.
- **Conclusion** at full Points — Plot Armor lifts; treat as Random Event with Current Context Focus. May resolve in this Scene; if not, delay to next Scene without CF testing.
> Detail: `→ rules/05-variations.md` §The Thread Progress Track.

### Diversifying Threads

Break a single broad Thread into 2–3 narrower aspects. ("Transport the scientist" → "Transport scientist", "Find why he's hunted", "Avoid the Syndicate".) Random Event rolls become more granular.
> Detail: `→ rules/05-variations.md` §Diversifying Threads.

### Resolving Character vs Player Knowledge

Four strategies when the Player knows more than the PC:
- **Test It, Ask It, Then It's Real** — PC must successfully test for the hidden thing before its existence is confirmed.
- **Reliable vs Unreliable** — Player knowledge is "potential" until the PC encounters it; can prove wrong.
- **Going With It** — embrace omniscience cinematically.
- **Extra Knowledge As RP Opportunity** — the gap *triggers* a roll for the PC to earn the knowledge.
> Detail: `→ rules/05-variations.md` §Resolving Character Vs Player Knowledge.

### Conclusive Adventure Conclusions

If the main Thread stalls: choose **Move Toward A Thread** as Focus on an Interrupt Scene (with the specific Thread). Use sparingly. When the conclusion arrives, ramp up interpretations and let Yes mean *more* than it normally would (use Context to power emotional weight).
> Detail: `→ rules/05-variations.md` §Conclusive Adventure Conclusions.

### Choose Your Chaos Flavor

Switch to a less-chaotic Fate Chart by choosing a variant column scheme (`→ tables/fate-chart-variants.md`):
- **Mid-Chaos**: CF columns 1, 2-3, 4-6, 7-8, 9.
- **Low-Chaos**: CF columns 1-2, 3-7, 8-9.
- **No-Chaos**: ignore CF entirely; answers depend only on Odds. Useful for replacing RPG rules.
For Random Events / Expected Scene tests, you can still track CF normally OR clamp it to a narrow range (e.g., always 5).
> Detail: `→ rules/05-variations.md` §Choose Your Chaos Flavor.

### Session Definition In Solo Play

Don't measure sessions by time or Scene count. Measure by **Thread accomplishment** — a session ends when an important Thread resolves (or you choose to stop). For lesser Threads, multiple may be needed.
> Detail: `→ rules/05-variations.md` §What Is "A Session" In Solo Play?.

### Keyed Scenes

Pre-plan a future Scene with a Trigger and an Event. When the Trigger fires (during a Scene), the Event happens in the **next** Scene. Triggers can be deterministic (Count = 5) or randomized (1-3 on d10) or compound. Up to 5 Keyed Scenes tracked on `→ sheets/keyed-scenes.md`. Resolve the Event as a Random Event with Current Context Focus.
> Detail: `→ rules/05-variations.md` §Control Your Adventures With Keyed Scenes.

### Using Mythic With Prepared Adventures

When running a published adventure as a solo session:
- **Scaling**: Diminisher Value (rough fraction comparing PC strength to designed group strength). Apply to NPC numbers, HP, damage, hazards.
- **Read minimally** — section by section, only what you need to know now.
- **Lists**: pre-populate with key NPCs/Threads from the intro; add an **Adventure Features List** (`→ tables/adventure-features.md`) for module-specific encounters.
- **Use the Prepared Adventure Event Focus Table** (`→ tables/adventure-features.md`) instead of the standard Focus Table — it includes Adventure Feature and removes module-supplied results (Remote Event, New NPC, Move Toward/Away/Close A Thread, Ambiguous).
- **Don't use Altered or Interrupt Scenes**. Test the Expected Scene only for whether a Random Event fires; the Event is *added* to the Scene, not replacing it.
- **Conflicts**: when Mythic generates something that contradicts the prepared text, the Mythic change wins (the prepared content was potential until played).
> Detail: `→ rules/05-variations.md` §Using Mythic With Prepared Adventures.

### Handling Complicated Campaigns

- **List Editing With "I Dunno Rule"**: instead of pruning at end-of-Scene, wait until a List roll surfaces an element that triggers I Dunno — that's the signal to cut.
- **Start Fresh**: end the adventure when it gets fractured; begin a new one. The First Scene's exemption from CF/Random Events lets you reset cohesion.
- **Multiple Lists**: split the master Threads/Characters Lists by PC, region, or theme. Same element can appear on multiple Lists. Edit the active List during Bookkeeping.
> Detail: `→ rules/05-variations.md` §Handling Complicated Campaigns.

### Peril Points

A pool of Player tokens that can be spent at any time to **change the narrative** and avert PC doom. Default pool: **2 per adventure**. Resets per session, or one-shot — pick before play. When spent, you rewrite the moment so the threatened outcome doesn't occur (rope cut → catches a balcony 15ft down).
> Detail: `→ rules/05-variations.md` §Peril Points.

### Using The Adventure Crafter With Mythic

Combining Word Mill's *Adventure Crafter* (Turning Points, Plot Points) with Mythic:
- First Scene: generate 2-3 Turning Points for richness.
- **Use Crafter only for Interrupt Scenes**, never Altered.
- Use **Mythic Lists**, not Crafter Plotlines (they map onto Threads).
- Rolling on a List for a Plot Point: roll on the *full* List regardless of fill state (2d10 — section then row); blank lines get extra Choose options (Add Thread / Add Character).
- Only NPCs go on the Characters List; PC eligible to be Chosen but not listed.
> Detail: `→ rules/05-variations.md` §Using The Adventure Crafter With Mythic.

## Decision Tree

- "Stuck on a long-running Thread" → Thread Progress Track or Conclusive Adventure Conclusions.
- "PC keeps dying / sessions keep aborting" → Peril Points.
- "Want a calmer game tone" → Mid/Low/No-Chaos Fate Chart.
- "Want guaranteed plot beats" → Keyed Scenes.
- "Adventure feels fractured" → Start Fresh + Multiple Lists when next adventure starts.
- "Running a published module" → Prepared Adventures variant block.
- "Want player knowledge to not spoil things" → Test It / Reliable vs Unreliable / RP-Opportunity.

## Failure modes

- **Stacking too many variations** — pick at most 2-3 active ones; complexity has diminishing returns.
- **Using Thread Progress Track on too many Threads** — defeats the purpose; one Focus Thread at a time.
- **Spending Peril Points to overrule everything** — they're for narrative-ending moments, not minor setbacks.
- **Forgetting that Prepared-Adventure mode disables Altered/Interrupt** — stick to "Expected + maybe Random Event added in".
- **Overusing Move Toward A Thread choice for conclusions** — once or twice an adventure; otherwise it stops feeling earned.
