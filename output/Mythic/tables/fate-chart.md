# Fate Chart

> Source: *Mythic GME 2e* p.20, p.195 (collected sheets).
> When: Resolving a Fate Question via the Fate Chart method.
> Input: Odds (row) + current Chaos Factor (column).
> Output: Three thresholds for a 1d100 roll. Each cell reads as `ExcYes ≤ / Yes ≤ / ExcNo ≥`.

## How To Read A Cell

Each cell shows three numbers: `A / B / C`.

- Roll **≤ A** → **Exceptional Yes**
- Roll **≤ B** (and > A) → **Yes**
- Roll **> B** (and < C) → **No**
- Roll **≥ C** → **Exceptional No**
- `—` (was `X` in the book) → that result is impossible at this Odds + Chaos Factor combination.

Then check for a Random Event: if the 1d100 was a **double-digit** (11, 22, 33, 44, 55, 66, 77, 88, 99) AND the single-digit value is ≤ current Chaos Factor → also a Random Event.
