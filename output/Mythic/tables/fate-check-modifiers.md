# Fate Check Modifiers & Answers

> Source: *Mythic GME 2e* p.26-27, p.196 (collected sheets).
> When: Resolving a Fate Question via the Fate Check method (2d10 sum, not 1d100 lookup).
> Input: Odds + current Chaos Factor.
> Output: Roll modifier; then read 2d10 + modifiers against the Answers table.

## Procedure

1. Form a Yes/No Question and assign Odds.
2. Apply both modifiers from the table below (Odds modifier + Chaos Factor modifier) to a 2d10 roll, summed together.
3. Look up the modified total on the Fate Check Answers table.
4. **Random Event check**: If both d10s rolled the **same number** (1+1, 2+2, …, 9+9, ignoring 0+0) AND the single-digit value is ≤ current Chaos Factor → a Random Event also fires. (Exceptional/Yes/No still applies as the answer.)

## Fate Check Modifiers

| Odds | Roll Modifier | | Chaos Factor | Roll Modifier |
|---|:---:|---|:---:|:---:|
| Certain           | +5   |  | 9 | +5  |
| Nearly Certain    | +4   |  | 8 | +4  |
| Very Likely       | +2   |  | 7 | +2  |
| Likely            | +1   |  | 6 | +1  |
| 50/50             | None |  | 5 | None|
| Unlikely          | -1   |  | 4 | -1  |
| Very Unlikely     | -2   |  | 3 | -2  |
| Nearly Impossible | -4   |  | 2 | -4  |
| Impossible        | -5   |  | 1 | -5  |

## Fate Check Answers

| Modified Roll Total | Fate Question Answer |
|:---:|---|
| **18-20** | Exceptional Yes |
| **11 or more** (and not 18-20) | Yes |
| **10 or less** (and not 2-4) | No |
| **2-4** | Exceptional No |
| **Doubles**, single-digit ≤ CF | Random Event (in addition to the Yes/No answer) |

> **Note on Exceptional ranges**: The total must **fall within** 18-20 or 2-4 to count as Exceptional. A modified roll of 22 is a regular Yes (not Exceptional). Modifiers can push the total past those ranges, in which case the result is just Yes/No.

## Worked Example (Safrid The Druid, p.27)

> Question: "Does the bridge look stable?"
> Odds: Nearly Impossible → -4. Chaos Factor: 6 → +1. Total modifier: **-3**.
> Player rolls 2d10: 3 + 3 = 6. Modified total: 6 - 3 = 3.
>
> - Result: 3 is below 11 → **No**.
> - 3 falls within 2-4 → **Exceptional No**.
> - Doubles rolled (3, 3); 3 ≤ Chaos Factor 6 → **Random Event** also triggers.
