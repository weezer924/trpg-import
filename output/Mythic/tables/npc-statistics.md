# NPC Statistics Table

> Source: *Mythic GME 2e* p.128, p.218 (collected sheets).
> When: Resolving an NPC's statistic (HP, AC, damage, etc.) on the fly via Fate Question.
> Input: An expected value + Fate Question result.
> Output: How the actual statistic compares to your expectation.

## Procedure

1. Decide the value you most expect (e.g., "small water elemental does 1d6 damage").
2. Pose: **"Does the NPC have a statistic value of X?"** Assign Odds based on confidence (high if the expectation is reasonable; 50/50 if it's a wild guess).
3. Resolve the Fate Question and apply the table.

## NPC Statistics Table

| Fate Question Result | "Does the NPC have a statistic value of X?" |
|---|---|
| **Yes** | The value is what you expect. |
| **Exceptional Yes** | The value is **higher** than you expect, by about **25%**. |
| **No** | The value is **lower** than you expect, by about **25%**. |
| **Exceptional No** | The value is **much lower** than you expect, by about **50%**. |
| **Random Event** | There is a **special condition** associated with this statistic. Generate a Random Event with automatic Event Focus = Current Context to flesh it out. |

## Worked Example (water elemental, 1d6 damage)

| Result | Adjusted value |
|---|---|
| Yes | 1d6 damage. |
| Exceptional Yes (~25% higher) | 1d8 damage. |
| No (~25% lower) | 1d4 damage. |
| Exceptional No (~50% lower) | 1d3 damage. |
| Random Event | 1d6 damage AND a special condition: e.g., Meaning roll "Proceed"+"Needs" → blow on bare skin causes additional damage as corrosive toxins try to digest the target. |
