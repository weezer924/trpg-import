# Random Event Focus Table

> Source: *Mythic GME 2e* p.37-44 (descriptions), p.198 (table). Choosing-the-Focus reference: p.44, p.199.
> When: A Random Event has been triggered (via a Fate Question's doubles rule or via an Interrupt Scene).
> Input: 1d100 — OR: choose the Focus directly when you have a clear narrative reason.
> Output: A Focus that tells you what aspect of the adventure the Event centers on. Then roll on a Meaning Table for inspiration and interpret.

## Random Event Focus Table

| 1d100 | Result |
|---:|---|
| **1-5**    | Remote Event |
| **6-10**   | Ambiguous Event |
| **11-20**  | New NPC |
| **21-40**  | NPC Action |
| **41-45**  | NPC Negative |
| **46-50**  | NPC Positive |
| **51-55**  | Move Toward A Thread |
| **56-65**  | Move Away From A Thread |
| **66-70**  | Close A Thread |
| **71-80**  | PC Negative |
| **81-85**  | PC Positive |
| **86-100** | Current Context |

## Focus Descriptions

| Focus | What it means |
|---|---|
| **Remote Event** | Something happened that the PC was not present for; they're learning about it now (a body, a rumor, news of a town destroyed). Introduces twists without direct PC involvement. |
| **Ambiguous Event** | Something happens that is neither clearly harmful nor helpful. Often vague; may turn into foreshadowing later. Don't try to figure out what it means now — leave room for it to resonate later. |
| **New NPC** | A new NPC enters the adventure; will likely be added to the Characters List after the Scene. If you have no idea who, ask Fate Questions or use Element Meaning Tables. |
| **NPC Action** | An existing NPC does something that impacts the adventure. **Roll on the Characters List** to see which NPC. The NPC need not be physically present — the Event only has to *involve* them. |
| **NPC Negative / NPC Positive** | Something bad / good happens to an NPC. Roll on the Characters List. Can be major (story-shifting) or minor (incidental). |
| **PC Negative / PC Positive** | Something bad / good happens to a PC. With a single PC, automatic; with multiple, choose the one most expected. |
| **Move Toward A Thread** | The PC moves a step closer to resolving an open Thread. Roll on the Threads List. |
| **Move Away From A Thread** | A new hurdle or setback hindering Thread progress. Should make the Thread *harder* but not impossible. Roll on the Threads List. |
| **Close A Thread** | A Thread is resolved or nullified. Roll on the Threads List. The Player removes it from the list afterwards. (Plot Armor protects a Focus Thread from being closed early — see `../rules/05-variations.md` §Plot Armor.) |
| **Current Context** | Whatever is happening right now is the Focus. From a Fate Question → use the Question's Context. From an Interrupt → directly related to current action. Adds a new layer to existing events. |

## Why No "New Thread"?

The Threads you follow are decided by *you*, not the adventure. Mythic presents opportunities and ideas, but you choose which to make priorities — so there's no random "new Thread" result. (Counterpart for Characters: New NPC.)

## Sidebar: Event Focus Overlap

The Focus is a **starting place**, not a constraint. A "PC Positive" interpretation could simultaneously involve a New NPC, a Move Toward A Thread, etc. If your interpretation involves multiple elements, that's a richer event — not a wrong answer.

## Sidebar: But, They're Not Here

When NPC Action / NPC Negative / NPC Positive invokes an NPC who couldn't physically be present, **the NPC is still involved — just not present**. Examples (Dillard Gang invoked while PC is on a plane):

- The pilot has the gang's tattoo — he's one of them, lying to the PC.
- En route, the radio picks up chatter: a settlement below is being attacked by the gang.
- The PC checks her pack and discovers her ammo is missing — taken by the gang during a previous encounter.

## Choosing The Event Focus (when you decide instead of rolling)

Choose the Focus, not roll, when one of these reasons applies. (Don't do this every time — once or twice is usually enough to redirect the adventure.)

| Event Focus | When to choose it |
|---|---|
| **Remote Event** | Your PC is expecting news from afar and now seems like a good time for it to arrive. |
| **Ambiguous Event** | The adventure has slowed and you are ready for a mystery to pursue. |
| **New NPC** | There is a logical reason for a new NPC to appear right now. |
| **NPC Action** | Your PC is waiting on the action of NPCs to move the adventure forward. |
| **NPC Negative or NPC Positive** | You want to shift focus onto an NPC right now, perhaps to develop new storylines. |
| **Move Toward A Thread** | The adventure has stalled and needs a push forward. Especially useful for an Interrupt Scene. |
| **Move Away From A Thread** *or* **PC Negative** | You want a new challenge for your PC to face. |
| **PC Positive** | Your PC is having a hard time and could use a break. |
| **Close A Thread** | The adventure has gotten complicated and you want to thin out the Threads List. |
| **Current Context** | The Random Event could help explain a Fate Question result. *Or:* a Random Event could be disruptive to the current action. |
