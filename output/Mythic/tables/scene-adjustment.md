# Scene Adjustment Table

> Source: *Mythic GME 2e* p.71-73, p.217 (collected sheets).
> When: Generating an Altered Scene and you want a randomized Tweak.
> Input: 1d10.
> Output: One element to change in the Expected Scene. Interpret in Context. Reroll if not possible.

## Scene Adjustment Table

| 1d10 | Result |
|---:|---|
| **1**     | Remove A Character |
| **2**     | Add A Character |
| **3**     | Reduce/Remove An Activity |
| **4**     | Increase An Activity |
| **5**     | Remove An Object |
| **6**     | Add An Object |
| **7-10**  | Make 2 Adjustments |

## Result Details

- **Remove A Character** — Choose the most logical Character to remove from the Expected Scene. If there are no NPCs in the Expected Scene, reroll.
- **Add A Character** — Choose the most logical NPC on the Characters List and add them.
- **Reduce/Remove An Activity** — Reduce the intensity of an active element in the Expected Scene, or remove it completely if that makes more sense.
- **Increase An Activity** — Increase the intensity of an active element.
- **Remove An Object** — Remove a significant object in the Expected Scene; choose whichever makes the most sense.
- **Add An Object** — Add a significant object. If nothing logical comes to mind, roll on a Meaning Table for inspiration.
- **Make 2 Adjustments** — Roll on the table again until you have two adjustments. **If "Make 2 Adjustments" comes up again, ignore and reroll.** If the two rolled adjustments conflict with each other, ignore the second and use only the first.
