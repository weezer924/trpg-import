## 1. 基本概念

- **Mystery**：一场完整故事（3–6 小时）。由 GM 主持，玩家扮演 10–15 岁 Kids。
- **时代设定**：架空 1980 年代。瑞典 Mälaren 群岛（主）/ 美国内华达 Boulder City（副）。
- **核心循环**：Kids 在无聊的日常（Everyday Life）中卷入 Loop 相关的怪异事件，靠彼此合作解开 Mystery。
- **骰子**：使用 d6。凡 **6** 点 = 1 success。大多判定只需 1 success。
- **Kids 不会死**，只会受 Conditions（见 §4）。
- **人数**：理想 3–4 人，范围 1–5 人。

---

## 2. 六大原则

1. 你的家乡充满奇异而非凡之物
2. 日常生活平淡且不宽容
3. 成年人触不可及、也不理解孩子
4. Loop 之地危险，但 Kids 不会死
5. 按"场景"而非"回合"推进（无 initiative）
6. 世界由 GM 与玩家共同描绘

## 3. Kid 角色构成

### 3.1 年龄与属性
- **年龄**：10–15
- **属性**（4 项，每项 1–5）：**Body / Tech / Heart / Mind**
  - Body：跑跳、打架、潜行、攀爬
  - Tech：理解机器、编程、撬锁、制造
  - Heart：社交、欺骗、人脉、说服
  - Mind：找弱点、理解他人、解谜、知识
- **属性点分配**：总点数 = 年龄；每项 ≥ 1，≤ 5
- **生日涨点**：每长一岁 +1 属性点；满 16 岁退役

### 3.2 Luck Points
- **初始值 = 15 − 年龄**
- 每次 session 开始时回满；session 间不可保留
- 每长一岁永久 −1 上限

### 3.3 Skills
- 共 12 项，每属性 3 项（见 §9）
- **初始总点数 = 10**；Type 的 3 项 Key Skill 可至 3 级，其余最高 1 级
- 判定时骰池 = 属性 + 技能

### 3.4 Items
- 普通 Item：+1 ~ +3 骰（取决于 GM 判定）
- **Iconic Item**：固定 +2 骰；不会丢失/损坏（除非玩家愿意）；只有该 Kid 可用；遗失则在 Mystery 结束前找回
- Mystery 之间，除 Iconic Item 外所有 Item 都会丢失

### 3.5 叙事元素
- **Drive**：为什么这个 Kid 愿意涉险解谜
- **Problem**：一件日常中困扰 Kid 的事；GM 用它制造 Trouble
- **Pride**：令 Kid 自豪的事；每 Mystery 可启用一次（见 §6）
- **Relationships**：对其他 Kid + NPC 的关系（连结剧情钩子）

## 4. Conditions（状态）

| Condition | 效果 |
|---|---|
| Upset（沮丧） | −1 所有骰 |
| Scared（惊恐） | −1 所有骰 |
| Exhausted（力竭） | −1 所有骰 |
| Injured（受伤） | −1 所有骰 |
| **Broken**（崩溃） | **所有判定自动失败** |

- 多个 Condition 累加（−2、−3…）
- 4 个轻度 Condition 全满后再受一个 → Broken
- 玩家自选要勾哪个 Condition（需符合叙事）
- 治疗方式：Lead 技能 / 休息 / 剧情

## 5. Trouble 与骰子判定

### 5.1 流程
1. GM 描述 Trouble；问玩家"你怎么做？"
2. 玩家描述行动；GM 指定要掷的 skill
3. 骰 (属性 + 技能) 颗 d6，数 6
4. 达到所需 success 数 → 成功

### 5.2 难度
| 难度 | 所需 success |
|---|---|
| 普通 Trouble | 1 |
| 极困难 | 2 |
| 几乎不可能 | 3 |

### 5.3 失败后果
- 可能勾 Condition
- 可能触发新 Trouble
- 可能触发 **Complication**（仍完成关键目的，但"出了岔子"——有但是；由 GM 裁决）

### 5.4 Special NPC 属性
特殊 NPC 可能有 special attribute（2 或 3 级）：对应方向的判定需要对应数量的 success。
例：wild currents 2 → 游过去需要 2 success；ferocious beast 3 → 硬拼需要 3 success，但绕过去只需 1。

## 6. Luck / Pride / Items 加成

### Luck Point
- 失败后花 1 点，**重骰所有未出 6 的骰**（不回退）
- 每次判定最多用 1 点
- 可与 Push 叠加

### Pride
- 每 Mystery 一次：**勾选 Pride，立刻获得 1 个自动 success**
- 可在判定后（失败 or 成功）使用；必须解释 Pride 如何帮到你
- 若 Mystery 跨多 session，每 session 可用一次

### Iconic Item
- 用法贴切时提供 +2 骰（GM 判定是否适用）

### Bonus Effects（买效果）
- 多余的 success（超过所需数）可买额外效果，效果列表见各技能
- 同一效果可重复买
- GM 决定哪些效果适用当下场景

## 7. Push / Help / Extended Trouble

### 7.1 Push the Roll
- 失败后可立即 push（一次一骰只能 push 一次）
- **必须先勾一个 Condition**，然后重骰所有未出 6 的骰
- 成功判定也可 push 以买更多 effect
- 如果原 Trouble 有 Condition 威胁，Push 后仍失败可能要勾 2 个 Condition

### 7.2 Help
- 一个 Kid 可以帮另一个 Kid：描述如何帮 → 施助者 +1 骰
- **一次判定最多接受 1 个 Kid 的帮助**
- 若失败，施助者与主骰者承担相同后果

### 7.3 Extended Trouble（高潮桥段）
1. **Set the Stakes**：失败会怎样
2. **Threat Level**：所需 success 总数
   - 普通 = Kids 数 × 2
   - 困难 = Kids 数 × 3
   - 几乎不可能 = Kids 数 × 4
3. **Make a Plan**：每个 Kid 决定用哪个技能、以什么顺序
4. **Play the Scenes**：每 Kid 轮流一个场景骰一次（可 push）
5. **Outcome**：
   - total sixes < ½ Threat → **完全失败**
   - ≥ ½ Threat → 可再勾 Condition 换额外 success（每勾 1 = +1 success；可直到 Broken）凑到 Threat → **妥协达成**（部分目标）
   - 直接达到 Threat → **完全成功**

特殊说明：Extended Trouble 中**不使用** NPC 的 special attribute（已并入 Threat Level）。

## 8. NPC 规则

- GM **从不**为 NPC 骰骰子；NPC 行动结果由 GM 裁定
- NPC 帮助 Kid 时，GM 可给 +1 / +2 / +3 骰（罕见）
- Kids 需要彼此依靠，不能总靠成年人
- 战斗没有 initiative：一次行动 = 一次判定

### 规避攻击
被 NPC 攻击/操纵时，骰对应技能规避：
- 物理攻击 → move
- 社交/引诱/谎言 → charm
- 需要理解才能避开 → comprehend
- 伏击、眼神机警 → investigate

## 9. 12 项技能详解

### BODY

**SNEAK**（潜行、藏匿、偷）
- Bonus：给别 Kid 1 success / 额外发现

**FORCE**（举重、打斗、耐受）
- Bonus：给别 Kid success / 震慑或羞辱 / 压制对手 / 夺取物品 / 打昏对手 / 同样 Trouble 下次免骰 / 避免附带伤害

**MOVE**（攀爬、平衡、快跑、追逐/逃离）
- Bonus：给别 Kid success / 引人注目 / 无人察觉

### TECH

**TINKER**（制造 / 操作机械、撬锁、开车）
- 制造 Item：GM 说明需要什么（Item / 成功的 calculate / comprehend / program / 时间 / 工具）
  - 成功 = 造出 +1 Item；bonus 可升到 +2 / +3、或加"耐用 / 多功能 / 隐蔽"
- Manipulate bonus：给别 Kid success / 同样 Trouble 免骰 / 快速 / 安静 / 炫耀

**PROGRAM**（编程、操控电子设备、感染病毒、控制机器人）
- 创建 Item：流程同 Tinker
- Manipulate bonus：给别 Kid success / 同样免骰 / 快速 / 得到新信息 / 炫耀

**CALCULATE**（理解技术物件；问 2 个问题）
- 问题列表：
  - 它的用途？
  - 它如何工作？
  - 我能怎么用它？
  - 谁造的？
  - 它可能造成什么问题？
  - 它违法吗？
- Bonus：每个效果多问 1 个问题 + 使用该信息时 +1 骰（累积至 +3）

### HEART

**CONTACT**（找到合适的人）
- 玩家指名人物 → 骰 → 成功则联络上；失败则 GM 可让此人反而来找麻烦
- Bonus：带来合适工具 / 治愈 1 Condition / 带更多帮手 / 再次联络免骰 / 知道重要情报 / 一次性当 +1~+3 Item

**CHARM**（魅惑、欺骗、说服）
- Bonus：他们继续相信你 / 结下长期关系 / 愿意为你冒险 / 说服他人相信你 / 被震慑/困惑/打动 / 爱上你

**LEAD**（激励同伴；安抚情绪）
- 先用 Lead 建立骰池给其他 Kid 使用：
  | Success | Dice Pool |
  |---|---|
  | 1 | 2 骰 |
  | 2 | 4 骰 |
  | 3 | 6 骰 |
- 不能给自己；只能在 Kid 听你安排时用；同时只能有一个骰池
- 失败：勾 1 Condition，询问其他 Kid 关系怎样受损
- **治疗**：私下陪伴某 Kid → 骰 → 成功治 1 Condition；失败你自己得同样 Condition；不能治 Broken
- Bonus：多治 1 Condition / 治自己 1 Condition

### MIND

**INVESTIGATE**（找藏物、懂线索、破谜、侦查；问 2 个问题）
- 问题列表：
  - 这里藏着什么？在哪？
  - 这是什么意思？
  - 这里发生过什么？
  - 怎么进入/离开/绕过某物？
  - 我能察觉到什么威胁？
  - 它在哪？
- 失败：误解信息 / 你的秘密被人发现 / 勾 Condition
- Bonus：多问 1 个 + 使用该信息时 +1 骰（累积至 +3）

**COMPREHEND**（掌握信息 / 图书馆查资料）
- GM 给信息，或让你自己编（在合理范围内）
- 失败：GM 给坏消息或错误信息（不告诉你是哪种）
- Bonus：额外信息 + 使用时 +1 骰（累积至 +3）

**EMPATHIZE**（理解人/动物/智能体；问 2 个问题）
- **必须先花时间观察或对话**才能骰
- 问题列表：
  - 他们的弱点？
  - 怎样让他们做某事？
  - 他们感受如何？
  - 他们想要什么？
  - 他们会做什么？
  - 他们在说谎吗？
- 失败：坏消息 / 错信息 / 触发坏事
- Bonus：多问 1 + 使用时 +1 骰（累积至 +3）

### 知识类技能重叠说明
Comprehend / Investigate / Calculate / Empathize 有时重叠。玩家与 GM 协商选合适技能，GM 有最终话语权。
