## Warband-specific 用法补充

下列关键词在 New Antioch 单位 profile / special rules / variant 中**频繁出现**或**有 faction 调色用法**。**定义不变**（见 `rules/03-keywords-glossary.md`），但记录此处便于 Pass 8 单位作者 / MCP 解析参考。

### `NEW ANTIOCH` (Tag)

→ `rules/03-keywords-glossary.md#new-antioch`

**v0.1 New Antioch 全部单位标准 keyword**——包括 Lieutenant / Sniper Priest / Trench Cleric / Yeoman / Trench Mole / Shock Trooper / Combat Engineer / Mechanized Heavy Infantry / Combat Medic。

某些 special rules 仅触发该 Tag 的模型（如 Trench Cleric 的 *Onward Christian Soldiers!*：友方 `NEW ANTIOCH` 模型 8" 内获 `NEGATE FEAR`）。

### `FIRETEAM` (Effect)

→ `rules/03-keywords-glossary.md#fireteam`

**v0.1 New Antioch faction special rule (p.23)**：可包含至多 2 个 Fireteams（Stosstruppen variant 升至 3 个），每个 Fireteam 由 Warband 中任意 2 个模型组成。**New Antioch Fireteams 享有 *Concentrated Attack* 异能**——同一联合 Activation 中若两人击中同目标，可花 3 BLOOD MARKERS 将第二次 Injury Roll 转为 Bloodbath Roll（即使目标未 Down）。

### `LEADER` (Effect)

→ `rules/03-keywords-glossary.md#leader`

**v0.1 New Antioch Lieutenant 自带**；**Papal States variant 的 Trench Cleric 也获**（替换 Lieutenant 角色作为战团领袖）。Morale Check 时加 +1 DICE（前提：模型未 Down 或 Out of Action）。

### `TOUGH` (Effect)

→ `rules/03-keywords-glossary.md#tough` · `errata/rules-commentaries.md#q5--tough-与其他防-down-规则的叠加顺序`

**v0.1 New Antioch Lieutenant 自带**。⚠️ 与 Machine Armour 的 *Standfast* 叠加时按字面顺序：TOUGH 先把首次 OoA 改 Down → Standfast 再把 Down 改 Minor Wound（同时见 errata）。

### `STRONG` (Effect)

→ `rules/03-keywords-glossary.md#strong`

**v0.1 NA Mechanized Heavy Infantry 自带**（PDF p.33）；**Alba variant 的 Lieutenant 与 Shock Troopers 免费获**（*Highland Strength*）。允许 2-Handed Melee Weapon 作 1-Handed 用，且 `NEGATE HEAVY`。

### `INFILTRATOR` (Effect)

→ `rules/03-keywords-glossary.md#infiltrator`

**v0.1 NA Trench Mole 自带**（Yeoman 升级 +10 👑，PDF p.30）；**Éire Rangers 的 Shock Troopers 可购**（+10 👑，*Fianna*）；**Stosstruppen 的 Shock Troopers 可购**（+10 👑，*Forward Positions*）。

Abyssinia *Flanking* 异能与 INFILTRATOR **不同**——Flanking 模型在 INFILTRATOR 之后部署、必须 ≥8" 远离敌方、可贴战场任意边沿部署。

### `SKIRMISHER` (Effect)

→ `rules/03-keywords-glossary.md#skirmisher`

**Éire Rangers variant**：Lieutenant 用 SKIRMISHER 替换其 *Hold Your Fire!* 异能（同 👑 成本，*Loose Formation*）；Shock Troopers 可购 INFILTRATOR + SKIRMISHER 组合（+10 👑，*Fianna*）。

### `NEGATE FEAR` (Effect derivative)

→ `rules/03-keywords-glossary.md#negate-keyword` · `rules/03-keywords-glossary.md#fear`

**NA 各 variant 高频出现**：
- Trench Cleric 自带（亦给 8" 内友方 NA 模型授予）
- Papal States *Swiss Guard*：Lieutenant + 4 模型免费获
- Alba *Bagpipes*：8" 内友方模型获
- Éire *Berserker*：升级后单位获
- Stosstruppen *Chemical Incense*：消耗 Holy Smoke 后获
- Abyssinia *Anfarro*：佩戴者获

### `NEGATE MINED` (Effect derivative)

→ `rules/03-keywords-glossary.md#negate-keyword` · `rules/03-keywords-glossary.md#mined`

**v0.1 NA Combat Engineer 自带**。Engineer 移入 MINED 标记地形不触发 Injury Roll；并可主动 *Defuse Mine*（Risky Success Roll）。

### `NEGATE SHRAPNEL` (Effect derivative)

→ `rules/03-keywords-glossary.md#negate-keyword` · `rules/03-keywords-glossary.md#shrapnel`

**v0.1 NA Engineer Body Armour** 自带（Combat Engineer 必装）。`SHRAPNEL` 攻击额外 BLOOD MARKER 效果被免疫；同时 *Ballistic Box Armour* 对 SHRAPNEL 攻击额外 -1 INJURY DICE。

### `IGNORE [MODIFIER]` — Alba `IGNORE DEFENDED OBSTACLE`

→ `rules/03-keywords-glossary.md#ignore-modifier`

**Alba variant 全员**（*Rampant Charge*）：忽略 `Defended Obstacle` 近战修正（PDF p.43 描述：½" 高地形障碍给近战 -1 DICE，被 IGNORE 后忽略）。**这是 `IGNORE [MODIFIER]` 的 faction-specific 实例**，不是新关键词；定义仍走 `rules/03-keywords-glossary.md#ignore-modifier`。
